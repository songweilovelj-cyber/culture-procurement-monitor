# 基金投资AI Agent V1.0

面向普通长期投资者的指数基金分析产品。V1.0 已经从静态 HTML 改为本地 Web 工作台，包含：

- Node 本地服务
- JSON 数据层
- 评分引擎
- 前端工作台
- 用户持仓存储
- 数据更新服务
- 产品研究文档

## 怎么用

```bash
npm start
```

然后打开：

```text
http://localhost:4173
```

页面使用流程：

1. 先选一个指数主题，比如半导体、AI、红利或沪深300。
2. 看中间的当前动作和新增仓位建议。
3. 调整持有周期和风险承受度，观察建议变化。
4. 看风险提示、复查触发器、组合重叠和同类基金比较。

## 当前功能清单

1. 指数主题分析
   - 当前自动归类 15 个主题
   - 已抓取 27612 只基金，其中指数型基金 6688 只
   - 半导体主题当前匹配 159 只相关产品
2. 评分引擎
   - 长期结构分、当前时点分、产品执行分、组合适配分
3. 行动建议
   - 正常买入、加速分批、分批买入、小额试探、等待回落、先观望、回避
4. 产品比较
   - 费率、跟踪误差、流动性、产品分
5. 组合重叠
   - 识别主题基金和已有持仓的重叠风险
6. 数据更新面板
   - 点击“立即更新数据”后调用本地数据更新服务
   - 更新完成后自动刷新基金池、顶部数据时间和评分模型
7. Macro AI
   - 根据政策利率趋势、PMI、信用脉冲、通胀趋势、流动性压力、市场波动、政策文本倾向自动判断宏观 regime
   - 前端不再要求用户手动选择宏观环境
8. 我的持仓
   - 支持添加、删除、修改金额/市值
   - 按金额自动换算仓位比例
   - 用户持仓保存到本地 `data/user-portfolio.json`
   - 公开发布时默认排除用户真实持仓，只保留样例组合

## 数据采集

当前基金池来自东方财富公开基金代码表：

```bash
npm run collect:funds
```

页面按钮调用同一套采集逻辑：

```http
POST /api/update-data
```

也可以读取更新状态：

```http
GET /api/update-data/status
```

采集后会更新：

- `data/fund-universe.json`
- `data/funds.json`
- `data/market.json` 中的数据源状态

## 数据收集 skill 建议职责

- 日频：净值、成交额、溢价/折价、费率、跟踪误差
- 周频：指数成分、权重、行业暴露、风格漂移
- 月频：宏观数据、估值、再平衡影响
- 事件驱动：政策、利率变化、监管与行业事件
